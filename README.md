# EcoSpace Roads AI: Пластик қалдықтарды ғарыштан бақылау жүйесі
1. Жобаның қысқаша сипаттамасы (Project Overview)
EcoSpace Roads AI — бұл жасанды интеллектті пайдаланып, спутниктен алынған суреттерді талдайтын инновациялық стартап, оның мақсаты — пластикалық қоқыс топтарын анықтау.
Ерекшелігі: Жоба тек қоқысты табумен шектелмей, қайта өңделген пластиктен жол жабындарын өндіруге арналған «шикізат» базасын жасайды (гексагональды құрылымдар), бұл ғарыштық технологияларды, экологияны және құрылыс саласын біріктіреді.
2. Шешілетін мәселе (The Problem)
Ластану: Каспий аймағында және Атырау облысының далаларында қолжетімділігі қиын қоқыс полигоны мен пластик жинақтары.
Жолдар: Дәстүрлі асфальттың қымбаттығы және экологиялық материалдарды енгізу қажеттілігі.
3. Техникалық шешім (Technical Solution)
Жоба Sentinel-2 (ESA) спутнигінен алынған деректерді талдауға негізделген.
ЖИ-архитектурасы: Суреттерді сегменттеу үшін U-Net типтес конволюциялық нейрондық желі (CNN).
Әдіс: Алгоритм спектралдық индекстерді есептейді (FDI — қалқымалы қоқыс индексі), бұл ЖИ-ге полимерлерді судан және топырақтан ажырата білуге мүмкіндік береді.
Нәтиже: Координаттар мен жинайтын пластик көлемін бағалаумен карталарды автоматты түрде генерациялау.
4. Технологиялық стек (Tech Stack)
Тіл: Python 3.9+
ЖИ кітапханалары: TensorFlow, OpenCV, NumPy.
Ғарыштық суреттермен жұмыс: Rasterio, Earth Engine API.
Қоршаған орта: Google Colab / GitHub.
5. Бизнес-модель (Commercial Potential)
Жоба жоғары монетизация әлеуеті бар стартап ретінде бағаланады:
B2G (Business to Government): Экология министрлігі мен әкімдіктерге аналитикалық деректерді жеткізу.
B2B (Business to Business): Қалдықтарды қайта өңдеу компаниялары мен жол-құрылыс фирмаларына деректерді сату.
Әсері: Пластик жинау кезінде логистика шығындарын 30% азайту.
6. MVP құрылымы
Осы репозиторийде ұсынылған прототип (MVP):
.tiff немесе .png форматындағы спутниктік суреттерді жүктейді.
Алдын ала өңдеуден өткізеді (бұлттарды жою).
Ластану аймақтарын анықтау үшін ЖИ моделін қолданады.
